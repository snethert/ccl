## What was measured

The same eight hand-built function definitions are installed as one bundle or as separate callable instances. The dispatcher makes real same-module direct calls, same-instance indirect calls or cross-instance indirect calls. Unknown targets, nested calls and tail transfers retain indirect dispatch where required. Every configuration eagerly installs all eight definitions before timing; the correctness corpus separately exercises lazy installation. V8 is pinned to Liftoff-only execution with tier-up and lazy compilation disabled. This is a recorded baseline-tier experiment, not optimized-engine or browser evidence.

All eight workloads run for all three candidates and packaging choices. A seeded synthetic matrix is retained before timings. Three independent paired trials per packaging create fresh Worker isolates and a fresh shared heap for each candidate; candidate, workload and packaging orders are randomized. This yields 27 candidate/trial rows and 216 workload rows, each with at least 100 ms warmup and 50 ms sampling. Every warm/sample batch traverses complete 32-record schedules, preserving the subcase mix across candidates. The first batch is retained separately.

The Wasm loop consumes the first-value/count pair and every result through an address-independent graph observation. Its independent JavaScript oracle includes sharing, cycles and moved conses. Frame/root publication and restoration, staging, bindings, cleanup, result ownership, polls, graph observation, boundary admission/parking and runtime schedule counters stay in the timed path. Host inspection packets, assertions and trace forwarding are outside timing. Those diagnostic paths execute during qualification against the same emitted bytes. Policy 1 still materializes roots; its actual storage is charged.

Raw first/warm/sample batches, complete input schedules, code and metadata bytes, adapter/stub bodies, table slots, stack/root observations, compilation/instantiation components and Worker memory reports are retained. Compilation/startup means fresh Worker isolates in an existing Node process, with the cache state unqualified; it does not measure image restoration or browser caching. Reserved shared linear memory is distinguished from per-slot regions within that same allocation. Process-wide RSS is not per-Worker resident memory. See the fixture README for exact counters and unavailable metrics.

## Verification and interpretation

The explicit ownership reader counts physical scanner addresses and verifies advertised result counts at legal inspection points. It catches duplicate result ownership before collection in the deterministic inspection case. A private code/role/function registry guards publication and checks the real table; its control replaces an actual entry. The circular APPLY case is accurately named as reaching argument capacity, without claiming a cycle detector. These changes implement the three nonblocking follow-ups from Claude's fourth audit without changing the reviewed r1 fixture.

The statistical report retains paired geometric-mean ratios and 10,000 seeded bootstrap resamples over whole trials, preserving all candidate/workload pairs. The checker has ten controls for known ratios, common trial drift, reproduction, missing/duplicate/invalid data and insufficient trials/durations. The report always says NO_SELECTION. Three trials and the exploratory durations are below the unchanged benchmark policy's minima; uncertainty and every unresolved correctness/resource/product requirement remain visible. No threshold or workload weight in benchmarks.json has changed.

Original development r1 retains a WAT import-order build error; development r2 retains the Node --input-type flag inheritance failure. Development r3/r4 passed the initial cross-instance/direct slices. Formal prototype r1 passed the complete corpus and collected exploratory timings, but its tail sampler could stop after a partial input cycle and its high-water counters accumulated across workloads. R2 uses whole cycles, resets the workload counters and checks cleanup/tail counts and stack/root bounds per batch. All original artifacts remain retained with their original dispositions; no earlier result is silently repaired.

Fresh r1/r2 rebuilds reproduce all 4,518 Wasm modules and objects byte-for-byte; the 864 unchanged reviewed prerequisites also match their original pack. All 23,760 S0-LL21-a artifact identities are verified. An independent Python calculation reproduces every paired ratio and bootstrap interval from the raw trials.

## What is next

Independent review of this derivative and its evidence precedes project acceptance of S0-LL21-a. The complete S0-ENGINE-a and S0-CONTRACTS-a prerequisites still block selection. Extend resource and phase-latency instrumentation, then explore larger module/startup/Worker configurations and the optimized tier under the [product-risk plan](product-risk-plan.md). A qualified census must supply representative function counts and workload/call weights, and product startup/memory budgets must be stated before a representative matrix and selection trials are frozen.

The current bounds remain eight definitions, 32 arguments, six values, four ownership slots, two live measurement Workers, 16 KiB C and explicit stack reservations per slot, a shared 1 MiB memory and 4 KiB semispaces. They establish no arbitrary-size, generated-code, production pause or full-image startup claim. Native census instrumentation and a real shared-compiler pass 2 require an authorized author under the standing rules. H(G) remains optional future work and blocks no scheduled stage.
