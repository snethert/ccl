# IDE reference screens

The twenty-three reference screens for [ui-overview.md](../ui-overview.md),
one JPEG per screen, numbered as in its §32. Each image is the page image
embedded in the source PDF, extracted byte for byte, not re-rendered:
4320 × 2700 pixels, a 1440 × 900 frame at 3×.

Source: `CLIM_IDE_Screen_4.pdf`, 23 pages, sha256
`a7d4e2dea4e7b1f4d6342a7a44a1374c2749f91c460ef14567ff4a4374e172fb`. The PDF is not
committed; it is the same 23 JPEGs in a page wrapper.

The screens are worked examples, not evidence. Where a screen disagrees with
the text, §33 of the design document says which one is wrong. The screens
are dark-theme only; the light variant is registered as undecided in §27.
