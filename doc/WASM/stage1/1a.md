## Delivered

pass 2 for a declared leaf subset, and a cross-loader registration. It adds
three entries to `lib/systems.lisp` and a Wasm clause to each of the compiler
and cross-loader module selectors in `lib/compile-ccl.lisp`. All changes were
applied in disposable pristine U1 copies. Shared compiler and kernel files
in this checkout remain untouched. The user's authorship authorization
requires Claude's review before integration.

CCL's actual front end and registered pass 2 produce nine Wasm functions:
fixnum/NIL/T constants, argument references and nested IF. Twenty-four calls
in one real Worker agree with native evaluation. Unsupported forms are
refused before front-end folding, and unsupported IR is refused again by
pass 2. The cross-loader refuses heap/image construction until Stage 1E;
its registration is not a bootstrap implementation.

## Findings retained

A native TYPEP compiler macro folded 536,870,912 as a host fixnum before the
new pass 2 could reject it. The first compiler API now admits only the
explicit implemented source grammar before invoking the front end. TYPEP,
BIGNUM tests, EQL and arithmetic folds outside that grammar are tested
refusals. This does not implement those operations; integrating the qualified
target macro/helper environment is a prerequisite to widening the grammar.

Development also found missing NIL/T IR cases and a weak first-error mutant:
the last failure duplicated the first, hiding overwrites. The final flood
uses a different operation and rejects that mutant. Original attempts,
logs, sources and necessary binaries are retained by the development record.
The earlier R1 packet omitted loading the backend before the full rebuild
(its tests and snapshots did load it). It is superseded, unaccepted evidence.
The added rebuild check first exposed dependency-preparation differences;
those failed attempts remain retained. No generated symbol names or code
bytes are normalized to make the final comparison pass.

The [ARM survey follow-up](runtime-obligations.md) records runtime-global
ownership, binding growth, interrupt masking, recoverable stack exhaustion,
trap semantics and callback installation. Tags/NIL and constant-index limits
come from x8632; separate-code handling uses ARM as a reference. These are
implementation obligations, not new Stage 0 acceptance claims.
