# Backend Migration Ticket Subplans

This folder contains per-ticket implementation subplans referenced by:

- `doc/wasm/backend-migration-master-plan.md`

## Naming Convention

- `BPL-00-... .md`
- `BPL-01-... .md`
- `BPL-02-... .md`

## Sync Rule

Whenever a backend ticket subplan is updated, update the corresponding ticket block in:

- `doc/wasm/backend-migration-master-plan.md`

in the same change (status, notes, last-updated, and immediate next step).

If a cross-track dependency changes, also update:

- `doc/wasm/runtime-backend-dependency-matrix.md`
