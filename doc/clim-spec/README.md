# CLIM II Specification (local mirror)

Mirror of the CLIM 2 specification HTML from
http://bauhh.dyndns.org:8000/clim-spec/index.html, fetched 2026-09-25 with
`wget -r -np -k -p -E`. Internal links are rewritten for offline browsing;
start at `index.html` or `contents.html`.

Not mirrored: the site's per-section annotation/edit links (`edit/anno?...`)
and the "Apropos" search form, which are server-side features and still point
at the original host.
