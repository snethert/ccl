**One shared EQL implementation.** The proposal appends `ht_eql` to the reviewed EQL table module. The same instance exports `ht_run` for table lookup and `ht_eql` for the generated Lisp call. The first development candidate did build a separate copy; it was discarded on the user's correction before retention.
