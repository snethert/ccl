# Arch, hyperbolic and funcallable integration

470 original definitions execute (439 with a non-NIL witness); admission is
2,043/2,231. This integration adds no definition or slot credit.

Steve authorized acceptance and integration after audit 158. The runner takes
all shared files from the final reviewed packet, which stacks the arch,
hyperbolic and funcallable proposals. It verifies the packet and input hashes,
then checks the installed bytes against them. The final R6/R6a record is reused
only after every compiler, arch and CCL source file in its proposal matches;
21,843 tests passed and all 164 FASLs restored in that record.

From any checkout with the sibling `ccl-evidence` store:

```sh
python3 tests/wasm/stage1/bootstrap-funcallable-acceptance/run.py verify --output /tmp/ccl-funcallable-integration-check
```

This command works **after integration**. It does not re-import a proposal
patcher against the changed shared sources. It rebuilds the production float and
collector binaries, compares their bytes, and runs the retained generated cases
through the production runtime imports. The execution record must be byte-equal
to the reviewed record. Forty owner regressions, pinned-owner and structure
checks also run against production bytes.

The additional single-float observer compiles its native lambda on the pinned
kernel and image and invokes the retained target module before and after
movement at both placements. Native `(T T)` and target `(NIL NIL)` are recorded
as an architecture difference, not compared as equal. The observer projection
is explicit and carries no native-match credit.

[Storage and obligations](../../../../../doc/WASM/stage1/function-storage.md)
settles O-6's keyword-vector home, records O-7, and describes O-8's widened
installer profile. Ordinary keyword accessors and generic-function method
selection still require implementation. No source rewriter is integrated.

The original proposal verifiers remain replayable at their recorded proposal
commits. This runner is the post-integration check and uses immutable retained
inputs rather than deriving against a moving shared baseline.
