This reconstructs the previous development graph from its pinned inputs. To
reuse a cached copy, add `--base /absolute/path/to/census.json.gz`; its complete
identity must equal the preceding closure's recorded graph hash. Both paths
produce the same result. The output directory must be new and outside the
source/evidence repositories. **Exit 2 means the analysis completed and closure
remains BLOCKED.** Errors exit 1 and retain a failure record and source snapshots.

derived `facts.json.gz`, the additive `delta.json.gz`, all 95 classifications in
`classification.json`, the before/after `report.json`, and `controls.json`.

duplicated in the evidence store. Add
`--packet /Users/buildsomething/Source/ccl-evidence/2026-09-15-binding-definitions-r1`
to replay the complete stream and compare all six retained outputs.
